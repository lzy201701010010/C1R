# Reconstruct the frozen GSE266546 validation

1. Retrieve `GSE266546_Annotation_AC_Endoscopy.txt.gz` and `GSE266546_Raw_counts_AC_Endoscopy.txt.gz` from the GSE266546 GEO supplementary-file page. Check the recorded source sizes and SHA-256 values in `provenance/GSE266546_SOURCE_FILE_PROVENANCE.tsv`. Do not substitute later revisions without documenting the difference.
2. Use `definitions/hgnc_complete_set_2026-09-07.txt`, the frozen HGNC complete-set reference (SHA-256 `6f43d6ff43aa9fdfa5fb2f20a20a7cace66e6e02e2a0dcf19d9b726e2e248d20`). The original source was the [HGNC complete-set download](https://storage.googleapis.com/public-download-files/hgnc/tsv/tsv/hgnc_complete_set.txt); the candidate includes the exact frozen snapshot under HGNC's [CC0 gene-data license](https://hgnc.genenames.org/about/license/). Preserve its exact column schema and mapping rules from `methods/C1R_EV1_FROZEN_METHOD_LOCK.json`.
3. Use `definitions/` for the exact frozen 353-member GP_IBD non-overlap mask and four-member SP02 state. In the AC_Endoscopy annotation select Ascending Colon, Endoscopy, histology Mild/Moderate/Severe, and the exact 12 epithelial labels described in the method lock. PatientID is the donor unit; one donor has two samples, which are averaged equally.
4. Follow the original frozen Stage A semantics: verify exact barcode linkage and integer/nonnegative counts; map exact approved HGNC symbols, then unique frozen aliases/previous symbols or Ensembl identifiers; leave ambiguous entries unmapped; sum duplicate canonical rows; retain zeros in the 19,471-gene background. Expected arm counts are 15,989 cells, 19 samples, 18 donors, SP02 4/4, GP mask 324/353. Abort if any frozen gate fails.
5. Install Python 3.12 and R 4.4 (or compatible versions). In a fresh Python environment run `python -m pip install numpy==2.3.5 pandas==3.0.1 scipy==1.16.2`. The R drawing script uses base `graphics` and `grDevices` only. Put the two GEO `.txt.gz` files in a user-selected source directory; do not add them to this release package.
6. From this package root run `python scripts/reconstruct_ev1_from_geo.py --annotation SOURCE_DIR/GSE266546_Annotation_AC_Endoscopy.txt.gz --counts SOURCE_DIR/GSE266546_Raw_counts_AC_Endoscopy.txt.gz --hgnc definitions/hgnc_complete_set_2026-09-07.txt --output NEW_LOCAL_DIRECTORY`. Use the syntax for paths on your system. The script verifies source hashes and frozen gates, aborts on a result mismatch, and writes derived donor scores only to the caller's local directory. It never needs EV0–EV4 internal files. Fit only `z(SP02) ~ 1 + z(GP_IBD_nonoverlap)`; do not treat a mismatch as a new scientific result.
7. Generate the figure from the newly reconstructed local donor table with `Rscript scripts/EV2A_frozen_figure_source_reference.R NEW_LOCAL_DIRECTORY/DONOR_SCORES_LOCAL_ONLY.tsv results/C1R_EV1_PRIMARY_RESULT.tsv NEW_LOCAL_DIRECTORY/SF4_reconstructed`. The script writes a vector PDF, 600-dpi PNG, and a local-only X/Y table. Compare the figure and its 18 donor points with the supplied frozen SF4 PDF. Keep the local X/Y table out of any public release.
8. Required input columns are `Barcodes`, `SampleID`, `PatientID`, `Tissue`, `Source`, `Histology` and `Celltypes` in the annotation; the raw-count file has a barcode header and one feature row per gene. The candidate records exact source file names, sizes and SHA-256 values in `provenance/GSE266546_SOURCE_FILE_PROVENANCE.tsv`. The reconstruction program is deterministic and uses no seed.

The original gated Stage A and archival drawing scripts used private workspace paths and are retained in the EV4 internal audit, not in this public candidate. See the EV5A dry-run report for the independently executed reconstruction result. No third-party matrix or donor-level derived score is bundled.

# C1-R external-validation extension, local v1.1.0 candidate

This is a **local release candidate**, not a published GitHub or Zenodo version. It is an additive extension to the historical v1.0.0 release. The original C1-R analysis, its 21 registered mappings and reported results remain unchanged.

The new layer reports the prespecified GSE266546 validation of the single primary GP_IBD_GCST004131_V1 × SP02/INFLARE donor-level expression-score relationship. It includes the frozen method and definitions, aggregate result, Supplementary Figure 4, provenance, software record and reconstruction guidance. The test comprised 15,989 cells, 19 samples and 18 donors. It does not imply that the other 20 mappings replicated, nor establish mechanism, causality, clinical utility or guaranteed participant non-overlap. Source-lineage independence is bounded by pseudonymized cross-study identities.

GSE266546 matrices, annotations, exact third-party input objects, cell/sample records and donor-level score tables are **not redistributed**. Obtain the source directly from [GEO GSE266546](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE266546). The local `scripts/reconstruct_ev1_from_geo.py` and [reconstruction guide](RECONSTRUCTION.md) specify the frozen analysis. The frozen HGNC mapping reference is included because HGNC releases its gene data under [CC0](https://hgnc.genenames.org/about/license/). Donor-level derived scores can be reconstructed from the original source using that workflow; the source matrix must remain at its original repository.

The v1.0.0 historical snapshot remains at https://github.com/lzy201701010010/C1R/releases/tag/v1.0.0 and DOI 10.5281/zenodo.22829391. This directory has no successor DOI. The reconstruction script preserves the frozen Stage A and Stage B algorithms. The EV5A figure script takes user-provided donor-score and aggregate-result paths and uses only base R graphics. The EV4 source candidate failed the portability audit because its archival figure script used author-machine paths; the EV5A repaired candidate removes that dependence. This candidate's clean-room dry-run result is documented in the EV5A audit, not assumed by this README.

The MIT license from v1.0.0 applies only to author-owned code and documentation. HGNC gene data carry HGNC's CC0 terms. No additional blanket license is asserted for result tables, source datasets or participant-derived material. The figure and aggregate tables should retain provenance and citation on reuse.
